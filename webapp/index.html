How it works

The tool joins the MaxTime links sheet, the district master sheet, and the folder's filenames. It tells you which controllers still need their active database downloaded, which files are duplicated, and which master rows should be marked timing. It only ever reads: it never edits a sheet, a file, or a controller.

Everything runs in this browser tab. File contents and names stay on this computer; progress checkmarks are kept in this browser only.
